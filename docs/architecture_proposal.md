# Documentation Architecture Proposal
## Proposed Structure
- `/docs/user/`: High-level guides, "How-to" operations, UI maps.
- `/docs/ai/`: Tool references, operational rules, prompt engineering guides.
- `/docs/tech/`: Architecture blueprints, API maps, reverse engineering findings.
- `/docs/audit/`: Gap analysis, tribal knowledge, friction points.

## Migration Path
1. Move `ui_map.md` and `user_journeys.md` to `/user/`.
2. Move `ai_capabilities.md` to `/ai/`.
3. Move `tribal_knowledge.md` and `friction_points.md` to `/audit/`.
