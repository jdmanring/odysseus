# UI Map
## Sidebar & Navigation
- `#sidebar`: Main navigation panel.
- `#sidebar-toggle-btn`: Toggles sidebar visibility.
- `#rail-new-session`: Creates a fresh chat session.
- `#rail-chats`: Opens chat history.

## Action Buttons
- `#tool-cookbook-btn`: Opens the Model Server (Cookbook) modal.
- `#tool-memory-btn`: Opens the Brain/Memory modal.
- `#tool-theme-btn`: Opens the Theme Customization modal.
- `#tool-doclib-btn`: Opens the Documentation Library.
- `#mode-toggle`: Switches between Chat and Agent modes.

## Modals
- `#memory-modal`: Manage persistent facts, skills, and preferences.
- `#theme-modal`: Browse and create custom themes.
- `#cookbook-modal`: Launch, stop, and monitor model servers.
- `#settings-modal`: Global application preferences.

## Hidden Triggers
- **Session Rename**: Click the session name in the top header to trigger the `#rename-session-modal`.
