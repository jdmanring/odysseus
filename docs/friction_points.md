# Friction Points
1. **The "Plan Gap"**: AI forgetting to call `update_plan` leads users to believe the AI is stalled.
2. **The Hidden Rename**: No obvious "Rename" button exists; the trigger is the session title itself.
3. **Cookbook Latency**: There is no real-time "Loading" bar in the model picker while a server is booting.
4. **Skill Schema Blindness**: Importing skills via URL fails silently if the JSON schema is incorrect.
