# User Guide: Hidden UI Triggers & UX Tips

## Goal
Discover non-obvious interaction patterns that improve efficiency and control over the Odysseus interface.

## Interaction Guide

| Action | Trigger | Result |
| :--- | :--- | :--- |
| **Rename Session** | Click the **Session Name text** in the top header | Opens the `#rename-session-modal` |
| **Quick-Send** | `Enter` | Sends the current message |
| **New Line** | `Shift + Enter` | Adds a newline to the message input |
| **Close Modals** | `Esc` key | Closes any open modal or dropdown |
| **Focus Search** | `Ctrl + K` (or similar pattern) | Focuses the primary search/command bar |
| **Sidebar Resize** | Drag the `#sidebar-resize-handle` | Adjusts the width of the navigation panel |

## Expected Result
The user can perform administrative tasks (like renaming) without searching through settings menus.

## Troubleshooting / Tips
- **Common Issue**: Cannot find the "Rename" button $\rightarrow$ **Solution**: Remember that the session name itself is the button.
- **Pro Tip**: Use the rail buttons (`#rail-new-session`) for the fastest way to start a fresh context.
