# Documentation Templates

## 1. User Guide Template
- **Goal**: What is being achieved.
- **Prerequisites**: Requirements.
- **Instructions**: Step-by-step (with UI IDs).
- **Expected Result**: The outcome.
- **Troubleshooting**: Common fixes.

## 2. AI Ops Guide Template
- **Tool Name**: Name.
- **Purpose**: What it solves.
- **Input Spec**: Parameter table.
- **Golden Rule**: When to use vs. when to avoid.
- **Failure Recovery**: Error $\rightarrow$ Fix.

## 3. Technical Reference Template
- **Component**: Name.
- **Responsibility**: Role in system.
- **Data Flow**: Source $\rightarrow$ Process $\rightarrow$ Destination.
- **Key Files**: File paths.
